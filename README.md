# RuneChronicle

**Your RuneScape journey, automatically recorded.**

RuneChronicle is a local-first RuneLite adventure journal that records observable progress from the moment it is installed. It does not fabricate pre-install history.

## What it remembers

- Session, day, week, month, and custom-date recaps
- XP and levels gained
- Monster and boss kills
- Claimed loot with quantities, GE value, and High Alch value
- Searchable Drop History across the full local OSRS item catalog
- Supported activities and reward chests
- Collection Log additions, pets, quests, combat achievements, PBs, clues, deaths, and milestones when RuneLite can reliably observe them
- Export, import, and reset controls for Chronicle data

## Authentic imagery

Item imagery is rendered by RuneLite from the game item definitions. Monster and boss cards resolve the corresponding OSRS Wiki page thumbnail on demand and cache it for the RuneLite session, giving RuneChronicle automatic coverage for newly encountered and obscure NPCs without a hand-maintained portrait whitelist.

## Privacy

Chronicle history is stored locally. RuneChronicle has no cloud account, telemetry service, or credential collection. For monster/boss artwork only, RuneChronicle requests the OSRS Wiki page for the NPC name being displayed. It does **not** include your RuneScape name, account hash, Chronicle history, drops, login/session data, or credentials in those requests.

## Data portability

Use RuneChronicle settings to export a JSON backup, import a backup, or reset locally stored Chronicle history.

## Scope

RuneChronicle records events it can reliably observe after installation. Historical events from before installation are not invented or backfilled.
